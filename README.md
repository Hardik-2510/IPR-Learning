📚 Intellectual Property Rights (IPR) - Complete Educational Guide
📋 Project Overview
The Intellectual Property Rights (IPR) Educational Guide is a comprehensive, single-page web application designed as a complete learning resource for B.Tech Semester VI students enrolled in course IT5047 (Open Elective – II). This interactive platform provides detailed answers to 60+ questions across 6 major units, covering all aspects of Intellectual Property Rights including Patents, Copyrights, Trademarks, Industrial Designs, Geographical Indications, Trade Secrets, and Emerging Trends.

The system features an elegant dark-themed UI with smooth unit-wise navigation, rich visual content (flowcharts, tables, diagrams, timelines), keyboard shortcuts for power users, and fully responsive design optimized for desktop, tablet, and mobile devices.
