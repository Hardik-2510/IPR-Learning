# IPR | Intellectual Property Rights Learning Guide

A comprehensive, single-page web application designed as a complete learning resource for B.Tech Semester VI students. This interactive platform provides detailed answers to 60+ questions across 6 major units, covering all aspects of Intellectual Property Rights including Patents, Copyrights, Trademarks, Industrial Designs, Geographical Indications, Trade Secrets, and Emerging Trends.

---

## 🚀 Features

* **Comprehensive Content:** 60+ detailed questions across 6 major units covering all aspects of IPR.
* **Elegant Dark Theme:** Custom-designed dark-themed UI for comfortable learning experience.
* **Unit-wise Navigation:** Smooth navigation through different IPR topics and units.
* **Rich Visual Content:** Flowcharts, tables, diagrams, and timelines for better understanding.
* **Keyboard Shortcuts:** Power user shortcuts for faster navigation.
* **Fully Responsive Design:** Optimized for desktop, tablet, and mobile devices.
* **Interactive Elements:** ARIA labels and keyboard navigation for accessibility.

---

## 🛠️ Tech Stack

This project is built purely with frontend web technologies:

* **HTML5:** For semantic structuring of the application.
* **CSS3:** For styling, responsive design, and custom dark theme design system with CSS Grid & Flexbox.
* **Vanilla JavaScript (ES6+):** For interactivity, DOM manipulation, and page logic.
* **MathJax 3.x:** For mathematical notation rendering.
* **Unicode Emoji:** For visual icons throughout the application.

**Design Features:**
* Dark Mode with custom color palette
* Mobile-First Responsive Breakpoints (480px, 768px, 1024px)
* CSS Transitions & Keyframes for smooth animations
* ARIA Labels and accessibility support
* No external framework dependencies
* No build tools required
* Works offline after initial load
* Lightweight (~100KB total)
